# 标准公文格式 Word 工作流

一个用于生成和审查中文公文及公文风格报告的 Codex 技能。它先区分正式党政机关公文与参照公文版式的企业报告，再确认文书结构、字体和版式，最后逐页检查 Word 渲染结果。

## 适用范围

- 正式党政机关公文：按 GB/T 9704—2012 和具体机关要求核对必要要素。
- 企业报告：可以参照公文的字体与版心，但应标明为“参照公文版式的报告”。封面、目录和图表按报告需要决定。

本技能提供工作步骤与检查要点，不附带 Word 生成程序。使用时仍需具备可用的文档编辑、渲染工具及相应中文字体。

## 使用

将本仓库复制或克隆为 Codex 技能目录下的 `standard-gongwen` 文件夹，保留 `SKILL.md` 与 `references/` 的相对位置。之后可提出：

> 请按标准公文格式生成 Word，并先确认文书类型、封面、目录和版式。

已有模板、单位规定和当前用户要求优先。生成正式文件前，应核对现行标准原文及适用规定；本仓库中的参考资料是操作摘要，不能代替标准文本。
